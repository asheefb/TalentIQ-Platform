### 1. What are Controller Tests?
Controller tests verify:
* URL mapping 
* Request → Response flow
* HTTP status codes
* Request/Response JSON
* Validation & exception behavior

They do NOT test database or business logic.

### 2. Why Controller Tests?
Manual testing (Postman) every time Not required.

Bugs in request mapping go unnoticed
* Fast feedback
* Safer refactoring
* Confidence before deploy

### 3. What is MockMvc?
MockMvc simulates HTTP requests without starting the server.
* No Tomcat
* No real HTTP call
* Very fast

Think of it as fake browser + fake server.

### 4. Key Annotation: @WebMvcTest

    @WebMvcTest(UserController.class)
    class UserControllerTest {
    }
Loads only:
* Controller
* Filters
* Jackson
* Validation

Service, Repository, DB are NOT loaded.

### 5. Mocking Service Layer

    @MockBean
    private UserService userService;
* Creates a mock
* Injects it into controller
* Avoids calling real business logic

### 6. Inject MockMvc

    @Autowired
    private MockMvc mockMvc;

Used to perform HTTP requests.

### 7. Basic Test Structure

    @Test
    void testCreateUser() throws Exception {
        mockMvc.perform(...)
                .andExpect(...)
                .andExpect(...);
    }

### 8. POST API Test Example

    @Test
    void createUser_success() throws Exception {
    
        UserRequestDto request = new UserRequestDto();
        request.setName("Asheef");
        request.setEmail("asheef@gmail.com");
    
        when(userService.createUser(any()))
                .thenReturn(new ResponseDto(true, 200, "Success"));
    
        mockMvc.perform(post("/api/users")
                .contentType(MediaType.APPLICATION_JSON)
                .content(new ObjectMapper().writeValueAsString(request)))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.success").value(true));
    }

### 9. GET API Test Example
    
    @Test
    void getUsers_success() throws Exception {
    
        when(userService.getUsers(any()))
                .thenReturn(new ResponseDto(true, 200, "Success"));
    
        mockMvc.perform(get("/api/users")
                .param("pageNo", "0")
                .param("pageSize", "10"))
                .andExpect(status().isOk());
    }

### 10. JSON Assertions
    
    .andExpect(jsonPath("$.data").exists())
    .andExpect(jsonPath("$.message").value("Success"))
    .andExpect(jsonPath("$.status").value(200))

### 11. Testing Validation Errors

    @Test
    void createUser_validationFail() throws Exception {
    
        UserRequestDto request = new UserRequestDto();
    
        mockMvc.perform(post("/api/users")
                .contentType(MediaType.APPLICATION_JSON)
                .content(new ObjectMapper().writeValueAsString(request)))
                .andExpect(status().isBadRequest());
    }

### 12. Exception Handling Test

    when(userService.getUsers(any()))
            .thenThrow(new RuntimeException("Error"));

Expect:
    
    .andExpect(status().isInternalServerError());

### 13. Common MockMvc Methods

    | Method    | Purpose        |
    | --------- | -------------- |
    | get()     | GET request    |
    | post()    | POST request   |
    | put()     | PUT request    |
    | patch()   | PATCH request  |
    | delete()  | DELETE request |
    | param()   | Query params   |
    | header()  | Headers        |
    | content() | Request body   |

### 14. Common Assertions

    | Assertion               | Meaning           |
    | ----------------------- | ----------------- |
    | status().isOk()         | 200               |
    | status().isBadRequest() | 400               |
    | jsonPath()              | JSON value check  |
    | content().json()        | Full JSON compare |

### 15. What NOT to Test in Controller Tests
* Database queries
* Business logic
* Entity mapping
* Repository behavior

Those belong to Service / Repository tests.

### 17. Interview Questions (Must Know)
1. Difference between @WebMvcTest and @SpringBootTest?

    @WebMvcTest loads only web layer; @SpringBootTest loads full context.
2. Why MockBean?
  
    To isolate controller from service.
